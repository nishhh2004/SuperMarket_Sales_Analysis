# Supermarket Sales Analysis

## Overview
Analyzed supermarket transaction data to uncover sales patterns 
across branches, product lines and customer types.

## Tools Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn

## Key Insights
- Food & Beverages generates the most consistent sales across all branches
- Gender has minimal influence on average spending
- Strong correlation between quantity and total sales

## Dataset
Supermarket transaction data with branch, product line, 
customer type and sales information
